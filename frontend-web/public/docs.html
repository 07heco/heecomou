💚 健康检查

GET /api/v1/health 公开
健康检查端点，返回服务状态、数据库连接、Redis 连接信息。无需认证。
响应: { "status": "UP", "service": "heecomou-backend", "db": true, "redis": true }

🔐 认证模块 — Auth

POST /api/v1/auth/register 公开 限流: 10次/分钟
用户注册。使用用户名 + 密码 + 邮箱创建新账户，注册成功后可直接登录。

请求体

{
  "username": "string (必填, 3-50字符)",
  "password": "string (必填, 6-100字符)",
  "email":    "string (必填, 有效邮箱)"
}
响应: ApiResponse<UserVO>
POST /api/v1/auth/login 公开 限流: 10次/分钟
用户登录。验证用户名和密码，成功后返回 accessToken 和 refreshToken。

请求体

{
  "username": "string (必填)",
  "password": "string (必填)"
}
响应: ApiResponse<LoginResponse> — 包含 accessToken, refreshToken, userId, username, expiresIn
POST /api/v1/auth/refresh 公开
刷新 Token。使用 refreshToken 换取新的 accessToken + refreshToken，旧的 refreshToken 将被废弃。

请求体

{
  "refreshToken": "string (必填)"
}
响应: ApiResponse<LoginResponse>
POST /api/v1/auth/logout 需认证
用户登出。将当前 accessToken 加入黑名单，使其立即失效。
响应: ApiResponse<Void> — "登出成功"

👤 用户模块 — User

GET /api/v1/user/me 需认证
获取当前登录用户的个人信息。
响应: ApiResponse<UserVO> — id, username, nickname, email, phone, avatarUrl, createdAt
PUT /api/v1/user/profile 需认证
更新当前用户的个人资料（昵称、邮箱、头像等）。

请求体

{
  "nickname":  "string (可选)",
  "email":     "string (可选, 有效邮箱)",
  "avatarUrl": "string (可选)"
}
响应: ApiResponse<UserVO>
PUT /api/v1/user/password 需认证
修改当前用户的登录密码，需要提供原密码验证。

请求体

{
  "oldPassword": "string (必填)",
  "newPassword": "string (必填, 6-100字符)"
}
响应: ApiResponse<Void> — "密码修改成功"

📚 词库模块 — Vocabulary

GET /api/v1/vocabulary 需认证
获取当前用户的词库列表，支持分页。

查询参数

page: int (默认 1)
size: int (默认 20)
响应: ApiResponse<VocabListResponse> — { items, total, page, size }
GET /api/v1/vocabulary/search 需认证
按关键词搜索词库（匹配词汇、拼音、分类），支持分页。

查询参数

keyword: string (必填)
page:    int    (默认 1)
size:    int    (默认 20)
响应: ApiResponse<VocabListResponse>
GET /api/v1/vocabulary/{id} 需认证
按 ID 获取单个词汇详情。

路径参数

id: long (必填, 词汇ID)
响应: ApiResponse<VocabVO>
POST /api/v1/vocabulary 需认证 限流: 30次/分钟
添加新词汇到个人词库。

请求体

{
  "word":     "string (必填, 词汇文本)",
  "pinyin":   "string (可选, 拼音)",
  "category": "string (可选, 分类标签)"
}
响应: ApiResponse<VocabVO> — "词汇已添加"
PUT /api/v1/vocabulary/{id} 需认证
更新指定词汇的信息。

路径参数

id: long (必填, 词汇ID)

请求体

{
  "word":     "string (必填)",
  "pinyin":   "string (可选)",
  "category": "string (可选)"
}
响应: ApiResponse<VocabVO> — "词汇已更新"
DELETE /api/v1/vocabulary/{id} 需认证
删除指定词汇。

路径参数

id: long (必填, 词汇ID)
响应: ApiResponse<Void> — "词汇已删除"
POST /api/v1/vocabulary/sync 需认证
增量同步词库数据。基于 version 字段，仅返回版本号大于指定值的词库项，用于端侧词库同步。

请求体

{
  "version": "long (必填, 客户端当前最大版本号, 首次传 0)",
  "limit":   "int  (必填, 单次同步上限)"
}
响应: ApiResponse<VocabSyncResponse> — { items, hasMore, maxVersion }

✏️ 纠错模块 — Corrections

GET /api/v1/corrections 需认证
获取当前用户的纠错历史记录列表。

查询参数

limit: int (默认 20, 返回记录数上限)
响应: ApiResponse<List<CorrectionHistory>> — [{ id, userId, originalText, correctedText, source, createdAt }]
POST /api/v1/corrections 需认证
提交一条纠错记录。当语音识别结果被用户手工纠正后调用。

请求体

{
  "originalText":  "string (必填, ASR原始识别结果)",
  "correctedText": "string (必填, 用户纠正后的文本)",
  "source":        "string (必填, 来源标识, 如 mobile/desktop/web)"
}
响应: ApiResponse<CorrectionHistory> — "纠错已记录"
