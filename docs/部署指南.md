# HeecoMou 云服务器部署指南

> **适用系统**：Ubuntu 22.04 LTS (64-bit)
> **推荐配置**：4 核 16GB RAM / 40GB 系统盘 / 50GB 数据盘 / 5Mbps 带宽
> **预计耗时**：首次部署约 30~45 分钟（含依赖下载）

## Step 0：重装前检查

> ⚠️ 如果服务器上**没有需要保留的数据**，直接跳到 Step 1。

```bash
# 1. 备份 MySQL 数据（如有）
mysqldump -u root -p --all-databases > ~/backup_$(date +%Y%m%d).sql

# 2. 备份自定义配置（如有）
cp -r /etc/nginx ~/backup_nginx_$(date +%Y%m%d)
cp ~/.bashrc ~/backup_bashrc

# 3. 下载备份到本地
# 在你的本地电脑执行：
scp root@<服务器IP>:~/backup_*.sql ./
scp -r root@<服务器IP>:~/backup_nginx_* ./
```

## Step 1：云控制台重装系统

### 阿里云轻量应用服务器

1. 登录 [阿里云控制台](https://swas.console.aliyun.com/)
2. 左侧菜单 → **服务器列表** → 找到目标服务器
3. 点击 **更多** → **重置系统**
4. 镜像选择：
   - **系统镜像** → Ubuntu
   - **版本** → Ubuntu 22.04 LTS
5. 设置 root 密码（记下来！）
6. 点击 **确认重置**
7. 等待 3~5 分钟，状态变为 **运行中**

### 腾讯云轻量应用服务器

1. 登录 [腾讯云控制台](https://console.cloud.tencent.com/lighthouse)
2. 点击目标实例 → **重装系统**
3. 镜像：**Ubuntu Server 22.04 LTS**
4. 设置密码 → **确定**
5. 等待完成

### 七牛云 ECS

1. 登录七牛云控制台
2. 实例列表 → 目标实例 → **更多** → **重装系统**
3. 选择 Ubuntu 22.04 LTS
4. 设置密码 → **提交**

### 重装后第一步：防火墙放行端口

在云控制台的 **防火墙/安全组** 中添加以下入站规则：

| 端口 | 协议 | 用途 | 来源 |
|------|------|------|------|
| 22 | TCP | SSH | 0.0.0.0/0（或限定你的 IP） |
| 8080 | TCP | Go 网关 | 0.0.0.0/0 |
| 8081 | TCP | Java 后端 | 0.0.0.0/0 |
| 8082 | TCP | Python ASR | 0.0.0.0/0 |
| 3306 | TCP | MySQL | 127.0.0.1（仅本地） |
| 6379 | TCP | Redis | 127.0.0.1（仅本地） |

## Step 2：SSH 登录 + 基础配置

```bash
# 在你的本地电脑执行
ssh root@<服务器公网IP>
# 输入重装时设置的密码

# ===== 基础配置 =====

# 1. 更新系统
apt update && apt upgrade -y

# 2. 设置时区
timedatectl set-timezone Asia/Shanghai

# 3. 安装基础工具
apt install -y curl wget git vim unzip htop net-tools

# 4. 创建项目目录
mkdir -p /opt/heecomou
mkdir -p /opt/heecomou/logs
mkdir -p /data/mysql
mkdir -p /data/redis
```

## Step 3：安装运行时环境

### 3.1 安装 Docker + Docker Compose

```bash
# 安装 Docker
curl -fsSL https://get.docker.com | bash

# 启动 Docker
systemctl enable docker
systemctl start docker

# 安装 Docker Compose
curl -SL https://github.com/docker/compose/releases/download/v2.24.0/docker-compose-linux-x86_64 \
  -o /usr/local/bin/docker-compose
chmod +x /usr/local/bin/docker-compose

# 验证
docker --version          # >= 24.0
docker-compose --version  # >= 2.24
```

### 3.2 安装 Go 1.22

```bash
cd /tmp
wget https://go.dev/dl/go1.22.3.linux-amd64.tar.gz
tar -C /usr/local -xzf go1.22.3.linux-amd64.tar.gz

# 配置环境变量
cat >> ~/.bashrc << 'EOF'
export PATH=$PATH:/usr/local/go/bin
export GOPATH=$HOME/go
export PATH=$PATH:$GOPATH/bin
EOF

source ~/.bashrc
go version  # 验证：go version go1.22.3 linux/amd64
```

### 3.3 安装 Java 17

```bash
apt install -y openjdk-17-jdk

# 验证
java -version   # openjdk version "17.0.x"
javac -version  # javac 17.0.x
```

### 3.4 安装 Maven 3.9

```bash
cd /tmp
wget https://dlcdn.apache.org/maven/maven-3/3.9.6/binaries/apache-maven-3.9.6-bin.tar.gz
tar -C /opt -xzf apache-maven-3.9.6-bin.tar.gz

cat >> ~/.bashrc << 'EOF'
export PATH=$PATH:/opt/apache-maven-3.9.6/bin
EOF

source ~/.bashrc
mvn --version  # 验证
```

### 3.5 安装 Python 3.11 + pip

```bash
apt install -y python3.11 python3.11-venv python3-pip

# 创建项目虚拟环境
python3.11 -m venv /opt/heecomou/venv
source /opt/heecomou/venv/bin/activate

# 升级 pip
pip install --upgrade pip
```

### 3.6 安装 Node.js（可选，前端工具链需要）

```bash
curl -fsSL https://deb.nodesource.com/setup_20.x | bash -
apt install -y nodejs
node --version  # 验证
```

## Step 4：克隆项目 + 配置

### 4.1 克隆代码

```bash
cd /opt/heecomou
git clone https://github.com/07heco/heecomou.git app
cd app
```

### 4.2 配置环境变量

```bash
# 创建环境变量文件
cat > /opt/heecomou/app/.env << 'EOF'
# 服务端口
GATEWAY_PORT=8080
BACKEND_PORT=8081
ASR_PORT=8082

# MySQL
MYSQL_ROOT_PASSWORD=heecomou123
MYSQL_DATABASE=heecomou

# Redis
REDIS_PORT=6379

# JWT 密钥（请替换为自己的随机字符串）
JWT_SECRET=heecomou_jwt_secret_change_me_in_production

# Python 虚拟环境
VENV_PATH=/opt/heecomou/venv
EOF

# 加载环境变量
source /opt/heecomou/app/.env
```

### 4.3 修改 docker-compose.yml（适配服务器路径）

```bash
# 查看当前 docker-compose.yml
cat /opt/heecomou/app/docker-compose.yml
```

> 如果 volumes 使用的是相对路径，需要改为绝对路径（以下操作视情况而定）：

```bash
cd /opt/heecomou/app
# 确保 volumes 路径正确
sed -i 's|mysql-data:/var/lib/mysql|/data/mysql:/var/lib/mysql|g' docker-compose.yml
sed -i 's|redis-data:/data|/data/redis:/data|g' docker-compose.yml
```

### 4.4 修改 Java 配置（适配服务器数据库地址）

编辑 `backend-java/src/main/resources/application-dev.yml`：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/heecomou?useUnicode=true&characterEncoding=utf8mb4&serverTimezone=Asia/Shanghai
    username: root
    password: heecomou123
    driver-class-name: com.mysql.cj.jdbc.Driver
  data:
    redis:
      host: localhost
      port: 6379

jwt:
  secret: heecomou_jwt_secret_change_me_in_production
```

### 4.5 安装 Go 依赖

```bash
cd /opt/heecomou/app/gateway-go
go mod tidy
go build -o /opt/heecomou/gateway ./cmd/gateway/
```

### 4.6 编译 Java 项目

```bash
cd /opt/heecomou/app/backend-java
mvn clean package -DskipTests
# 产物在 target/heecomou-backend-0.1.0-SNAPSHOT.jar
```

### 4.7 安装 Python 依赖

```bash
source /opt/heecomou/venv/bin/activate
cd /opt/heecomou/app/asr-python
pip install -r requirements.txt
# ⚠️ 首次安装 torch/transformers 约需 5~10 分钟
```

## Step 5：启动全部服务

### 5.1 启动 MySQL + Redis（Docker）

```bash
cd /opt/heecomou/app
docker-compose up -d

# 等待 MySQL 就绪（约 10s）
sleep 15
docker-compose ps
# mysql 和 redis 的 STATUS 应显示 "healthy"
```

### 5.2 启动 Java 后端

```bash
# 后台启动
nohup java -jar \
  -Dserver.port=8081 \
  -Dspring.profiles.active=dev \
  /opt/heecomou/app/backend-java/target/heecomou-backend-0.1.0-SNAPSHOT.jar \
  > /opt/heecomou/logs/backend.log 2>&1 &

echo $! > /opt/heecomou/logs/backend.pid
```

### 5.3 启动 Python ASR 服务

```bash
source /opt/heecomou/venv/bin/activate

# 后台启动（无 GPU 模式）
nohup python /opt/heecomou/app/asr-python/src/main.py \
  > /opt/heecomou/logs/asr.log 2>&1 &

echo $! > /opt/heecomou/logs/asr.pid
```

> **注意**：Python ASR 服务启动时如果没有 GPU，模型推理会很慢（3~5s 一句话）。功能验证没问题，实时演示建议用 GPU 服务器或端侧模式。

### 5.4 启动 Go 网关

```bash
# 后台启动
nohup /opt/heecomou/gateway \
  > /opt/heecomou/logs/gateway.log 2>&1 &

echo $! > /opt/heecomou/logs/gateway.pid
```

### 5.5 检查所有服务状态

```bash
# 查看进程
ps aux | grep -E "gateway|heecomou-backend|asr-python|mysql|redis"

# 查看日志
tail -20 /opt/heecomou/logs/backend.log
tail -20 /opt/heecomou/logs/asr.log
tail -20 /opt/heecomou/logs/gateway.log
```

## Step 6：验证部署

### 6.1 健康检查

```bash
# Java 后端
curl http://localhost:8081/api/v1/health
# 预期：{"status":"UP","service":"heecomou-backend"}

# Python ASR
curl http://localhost:8082/health
# 预期：{"status":"UP","service":"asr-python","model_loaded":false}

# Go 网关
curl http://localhost:8080/health
# 预期：{"status":"UP","service":"gateway-go"}
```

### 6.2 外网访问验证

在你的**本地电脑**上执行：

```bash
# 替换为你的服务器公网 IP
curl http://<服务器公网IP>:8081/api/v1/health
curl http://<服务器公网IP>:8082/health
curl http://<服务器公网IP>:8080/health
```

> 如果外网无法访问，检查云控制台 **防火墙/安全组** 是否放行了 8080/8081/8082 端口。

### 6.3 WebSocket Echo 测试

```bash
# 在本地电脑上安装 wscat（如果没有）
npm install -g wscat

# 连接 Go 网关 WebSocket
wscat -c ws://<服务器公网IP>:8080/ws/echo

# 发送消息
> hello heecomou
# 预期返回：Echo: hello heecomou
```

## 附录：常用运维命令

### 服务管理

```bash
# ===== 查看服务状态 =====
# Java 后端
curl http://localhost:8081/api/v1/health

# Python ASR
curl http://localhost:8082/health

# Go 网关
curl http://localhost:8080/health

# MySQL + Redis
docker-compose -f /opt/heecomou/app/docker-compose.yml ps

# ===== 停止服务 =====
# 停止 Java
kill $(cat /opt/heecomou/logs/backend.pid)

# 停止 Python ASR
kill $(cat /opt/heecomou/logs/asr.pid)

# 停止 Go
kill $(cat /opt/heecomou/logs/gateway.pid)

# 停止 MySQL + Redis
docker-compose -f /opt/heecomou/app/docker-compose.yml down

# ===== 重启服务 =====
# 先停后启即可，命令同上

# ===== 查看实时日志 =====
tail -f /opt/heecomou/logs/backend.log
tail -f /opt/heecomou/logs/asr.log
tail -f /opt/heecomou/logs/gateway.log

# ===== 清理日志 =====
echo "" > /opt/heecomou/logs/backend.log
echo "" > /opt/heecomou/logs/asr.log
echo "" > /opt/heecomou/logs/gateway.log
```

### Docker 管理

```bash
# MySQL 连接
docker exec -it heecomou-mysql mysql -uroot -pheecomou123 heecomou

# Redis 连接
docker exec -it heecomou-redis redis-cli

# 查看容器日志
docker logs -f heecomou-mysql
docker logs -f heecomou-redis

# 重启容器
docker restart heecomou-mysql heecomou-redis
```

### 一键操作脚本

项目内置了服务管理脚本，位于 `scripts/manage.sh`：

```bash
cd /opt/heecomou/app
chmod +x scripts/manage.sh

# 启动全部服务
./scripts/manage.sh start

# 停止全部服务
./scripts/manage.sh stop

# 重启全部服务
./scripts/manage.sh restart

# 查看服务状态
./scripts/manage.sh status

# 查看日志
./scripts/manage.sh logs
```

### 更新代码后重新部署

```bash
cd /opt/heecomou/app
git pull origin main

# 重新编译 Go
cd gateway-go && go build -o /opt/heecomou/gateway ./cmd/gateway/

# 重新编译 Java
cd ../backend-java && mvn clean package -DskipTests

# 重启服务
/opt/heecomou/app/scripts/manage.sh restart
```
